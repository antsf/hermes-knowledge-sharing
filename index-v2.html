Giliran Kamu — Coba di Laptop Sendiri

4 langkah, langsung bisa dipakai hari ini.

1

Install Hermes (Linux / macOS / WSL2)

Buka Terminal, tempel perintah ini:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
2

Ambil token AI gratis di Neosantara

Daftar di app.neosantara.xyz pakai akun Google atau GitHub (langsung jadi, tanpa nunggu email verifikasi). Dapat saldo gratis Rp 20.000 + reset Rp 10.000 tiap bulan. Ambil API Key di halaman /api-keys setelah masuk.

3

Hubungkan ke Hermes

Di Terminal yang sama, jalankan:

hermes model

Pilih "custom endpoint", isi Base URL https://api.neosantara.xyz/v1 dan API Key yang tadi diambil.

4

Mulai chat

Jalankan hermes di Terminal, dan langsung ngobrol. Selesai.
